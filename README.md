# portfolio-website

This repository contains the source code for my professional portfolio website, built to showcase my academic profile, technical skills, projects, and internships in artificial intelligence and data science[cite: 1].

## Features
* **Modern & Responsive Design:** Built with Tailwind CSS for a sleek, dark-themed, mobile-friendly interface.
* **About Section:** Highlights educational background including B.Tech in CSE from Vignan Institute of Technology & Science, Diploma, and SSC[cite: 1].
* **Skills & Certifications:** Outlines technical proficiencies in C, Python, Machine Learning algorithms, Tableau, Power BI, and AWS GenAI certifications[cite: 1].
* **Featured Projects:** Direct links to interactive Streamlit applications (Census Data Analysis Dashboard and Heart Disease Prediction Dashboard)[cite: 1].
* **Experience & Internships:** Details professional experience from Prodigy InfoTech and Student Tribe[cite: 1].

## Tech Stack
* **HTML5**
* **Tailwind CSS** (via CDN)

## Setup and Local Development
1. Clone or download this repository to your local machine into a folder named `portfolio-website`[cite: 1].
2. Ensure your main HTML file is named `index.html`[cite: 1].
3. Double-click `index.html` or open it in any modern web browser to view the site locally[cite: 1].

## Deployment
This portfolio can be deployed instantly using platforms like Netlify Drop by dragging and dropping the project folder[cite: 1].
